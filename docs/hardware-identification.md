# 控制芯片识别记录

## 实物观察

用户读到的芯片表面刻印为 `st17h66be2gt2549shtl2854`。本项目按原样保存这串字符。尚无清晰照片或厂商包装标签，因此不能确认各段的分隔、大小写、批次编码或完整订货型号。

## 厂商资料

伦茨科技的[产品资料页](https://www.lenzetech.com/developDoc)列出 `ST17H66` 数据手册和 `ST17H66T` 数据手册，两者是不同条目。伦茨科技的[芯片汇总](https://www.lenzetech.com/news/20210303100122254)明确列出 `ST17H66B` 和 `ST17H66T` 两款。用户刻印以 `ST17H66B` 开头，因此**较可能**属于 B 系列；余下字符 `E2GT2549SHTL2854` 的含义未查到可靠的厂商解释，不能据此确认精确子型号、存储容量或生产日期。

伦茨科技的[ST17H66 灯控方案说明](https://www.lenzetech.com/news/20210519141419855)称：方案中的芯片接收 App 命令，并通过 PWM 输出控制 LED 模式变化。伦茨科技的[智能照明方案说明](https://lenzetech.com/news/20211022105835137)列出 BLE、PWM、UART、SPI 等芯片能力。这些资料说明该芯片系列可以用于灯控；它们不是本台“极梦匠”灯组的电路图或固件说明。

## 对本项目的意义

1. 芯片型号提供硬件能力线索。它不能证明本台设备实现了厂商参考方案中的 Mesh、定时、音乐律动或其他功能。
2. APK 在“试色”时发送一条包含灯效编号的请求，未见逐帧发送颜色。结合厂商的 PWM 灯控方案，设备端执行呼吸等动画是合理推断，仍须通过实机观察确认。
3. 芯片资料不能给出 23 颗实体灯珠的电路连接、供电限值、固件版本或命令语义。不能把芯片的供电规格直接当作整块灯板的外部供电规格。
4. 当前不读取或写入固件，不使用 OTA 服务。新版 APK 到手后，先离线对比其哈希、版本、权限、BLE 服务与特征、命令号、报文布局、页面入口和动画调用，再决定是否做新的实机测试。
