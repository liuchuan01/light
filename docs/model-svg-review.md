# 独角兽模型 SVG 核对

## 素材质量结论

用户提供 `unicorn1.png` 作为设定画稿、`unicorn2.png` 作为蓝色灯位编号图。两图均为 844 × 681，正背视图排布一致，不需要拉伸配准。人工检查可辨认全部 1–23 号，没有发现遗漏或重复。按通道差值超过 10 统计，约 0.807% 的像素发生变化，主要为标注位置；此统计只辅助核对配准，不代替逐个编号检查。

这份素材可用于初步核对灯位，但当前自动提取结果过于杂乱，尚未达到最终界面的线稿质量。原始扫描有纹理、细线和较低分辨率，大幅放大后仍会看到路径折线和扫描噪声。当前输出保留可辨识的装甲结构，不宣称是精确 CAD、无损重建或实物发光边界测量。

原始 PNG 保持不变。输出是原生 SVG 路径，未将 PNG 作为图片嵌入 SVG。应用从同一个矢量线稿加载前后视图，再以独立路径显示配置颜色。

## 发光区域边界

- 按用户纠正，D1 从偏高的额头区域下移至双眼，使用两个眼部子路径。原图眼部很小，边界仍为简化示意。
- 按用户纠正，D14 改为腰腹横向灯带，替换原来中心两块路径，并调整引线锚点。灯带沿当前透视图略作折转，覆盖范围仍待更清晰参考图校正。
- 其余 21 项在标记所在部位的限定范围内提取红色结构。一个灯位可以有多段路径，例如前臂两条灯带。限定范围和命名可以在映射源中调整。
- 背面未标注的腿甲、头部等区域保持中性，不自动沿用正面灯位。隐藏编号不影响灯区选择。
- 线稿中的中性色不是已确认关灯状态，彩色区域也不等于真实亮度；这是一张配置示意图。

## 验证

逻辑测试检查 D1–D23 恰好各一项、正面 18/背面 5 的分配、协议索引不变、标签不超出视图，以及 SVG 没有嵌入 PNG。浏览器测试检查正背切换、图上选区、颜色变化、跨视图多选、编号网格联动、隐藏编号和键盘操作。

页面截图人工核对了前后裁切、编号遮挡和颜色显示。SVG 内的线稿与发光路径使用同一个 844 × 681 坐标系，前后切换只改变视框与裁切，不重新缩放某一图层。

## 重绘安排

当前脚本通过阈值分离深色装甲线、阴影和轮廓，再转为路径。它会保留原稿阴影、扫描噪点和细碎装甲线，不能代替面向界面的人工简化。暂保留当前主体作为定位底图，等待新的正背面设定图后，按外轮廓、少量结构线和独立发光区重绘；不对当前自动提取结果继续叠加细节。建议使用高分辨率、清晰、少阴影的正背面图，编号单独提供一份。
